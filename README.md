# 🎙️ Voice Virtual Assistant

A beginner-friendly **Python Voice Virtual Assistant** that can listen to voice commands and perform simple tasks.

This project was created to learn the basics of **Python, Voice Recognition, APIs, Web Browsing, and Automation**.

## 🚀 Features

The assistant can:

* 🎤 Take commands using your **voice**
* 🌤️ Tell the current **weather in Dhaka**
* ▶️ Open **YouTube**
* 📘 Open **Facebook**
* 💻 Open **GitHub**
* 😂 Tell **random jokes**
* 🌐 Open websites using voice commands
* 🗣️ Respond to the user using voice output

## 🛠️ Technologies Used

* **Python**
* `SpeechRecognition` — for recognizing voice commands
* `webbrowser` — for opening websites
* `requests` — for working with APIs
* `subprocess` — for voice output
* **Open-Meteo API** — for weather information
* **Free Joke API** — for random jokes

All APIs used in this beginner project are **free to use**.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### 2. Go to the project folder

```bash
cd Vertual Assistent_Jarvis

```

### 3. Install the required libraries

```bash
pip install SpeechRecognition requests
```

If you are using a microphone, you may also need the appropriate audio package for your operating system.

## ▶️ How to Run

Run the Python file:

```bash
python main.py
```

The assistant will start listening for voice commands.

For example:

```text
You: Open YouTube
Assistant: Opening YouTube...

You: Open GitHub
Assistant: Opening GitHub...

You: Tell me the weather
Assistant: Getting the weather update...

You: Tell me a joke
Assistant: Here's a joke for you...
```

## 🎤 Example Voice Commands

You can say:

```text
"Open YouTube"
"Open Facebook"
"Open GitHub"
"What's the weather?"
"Tell me the weather in Dhaka"
"Tell me a joke"
```

## 🌤️ Weather API

The project uses **Open-Meteo**, a free weather API, to get weather information.

No API key is required for basic usage.

The assistant can retrieve weather information for **Dhaka** and provide it to the user.

## 😂 Joke API

The assistant also uses a free joke API to retrieve random jokes.

This makes the project more interactive and fun while practicing API requests in Python.
